A coffeebreak dungeon dive in ASCII: sixteen floors under Charnfen, alone or with up to three friends.

**Downloads**
- Windows: unzip `Pyreheart-…-windows.zip` and run `pyreheart.exe`.
- Mac (Apple silicon): unzip `Pyreheart-…-macos.zip`. The game is not signed by Apple, so the first time, right-click `pyreheart` and choose Open.
- Linux: make `Pyreheart-…-linux-x86_64.AppImage` executable and run it.
- Android phone: open `Pyreheart-…-android.apk` on the phone and allow installing it.

A dive alone is saved after every move. Close the game whenever you like and choose "Go on with the dive" next time. A saved dive only loads in the same version of the game.

Playing together works on a home network straight away. Over the internet, the host opens port 7777 (TCP and UDP) on their router.
